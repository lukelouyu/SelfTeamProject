Add activities
Use add with FIXED timing or a FLEXIBLE window and duration.
Related commands: topic add, list, view

Replace the description, date, times, and ratings below with
your own values.

Example - add a fixed activity:
  add n/PL1101E Lecture c/ACADEMIC date/2026-08-15 type/FIXED from/09:00 to/11:00 energy/1 sensory/1 note/Bring laptop and charger

Example - add a flexible activity:
  add n/Finish assignment c/ACADEMIC date/2026-08-15 type/FLEXIBLE earliest/12:00 latest/18:00 dur/90 energy/4 sensory/2

Then view your activities:
  list
  list view/detail
  list date/2026-08-15

Optional - create and use a topic first:
  topic add c/ACADEMIC n/PL1101E
  add n/PL1101E Tutorial c/ACADEMIC date/2026-08-16 type/FIXED from/10:00 to/11:00 energy/2 sensory/2 topic/PL1101E

Edit an activity
Format: edit ID PREFIX/NEW_VALUE [PREFIX/NEW_VALUE ...]
Any subset of fields may be supplied, in any order. Stable IDs never
change. Every change is validated before the y/n prompt is shown.

Example - list first, then edit one field:
  list
  edit 3 energy/5

Example - change several fields at once:
  edit 3 n/CG3207 tutorial date/2026-08-17 topic/CG3207

Example - change a fixed activity's time:
  edit 3 from/14:00 to/15:00

Example - clear an existing note:
  edit 3 note/

After reviewing the before/after summary, answer y to save or n to
cancel (anything other than y is treated as n).

Find activities
Format: find [k/KEYWORD ...] [FILTERS]
Multiple keywords and filters use AND. k/ accepts one or two
words; three or more words is rejected.

Examples:
  find k/PL1101E
  find k/lecture
  find c/ACADEMIC
  find date/2026-08-15
  find k/PL1101E c/ACADEMIC
  find k/finish assignment order/time

Example - checking when nothing matches:
  find k/nonexistentkeyword12345

Every supplied keyword and filter must match. Search is
case-insensitive and can match part of a word.

Categories and topics
Topics are optional one-level groupings inside fixed categories.
Related commands: topic add, topic list, topic rename, topic delete

Example - create and use a topic:
  topic add c/ACADEMIC n/PL1101E
  topic list c/ACADEMIC
  add n/PL1101E Lecture c/ACADEMIC date/2026-08-15 type/FIXED from/09:00 to/11:00 energy/1 sensory/1 topic/PL1101E

Example - rename a topic:
  topic rename c/ACADEMIC old/PL1101E new/PL1101E Revision

Renaming asks for y or n before saving, and updates every
activity already using the old topic name.

Example - delete an unused topic:
  topic delete c/ACADEMIC n/Unused Topic

A topic cannot be deleted while any activity is still using it.

Reset all user data
Format: reset all
Shows a preview (how many activities, class schedules, and topics
exist) and a menu with three explicit choices - nothing is deleted
until you pick one. This cannot be undone.
Facility, connection, and academic-calendar reference data is
always kept, whichever choice you pick.

Choices:
  [1] Delete all user data - every activity and topic is cleared,
      the saved default order resets to chronological, and the
      next activity ID restarts at [1].
  [2] Delete other activities but keep class schedules - keeps
      every fixed lecture/tutorial/lab/section-teaching activity
      (the same activities recur can build on - see guide recur)
      with its original ID, note, and completion status, deletes
      everything else, and keeps only the topics still used by a
      kept activity.
  [3] Do not delete anything - cancels with no change.

Example:
  reset all
  2

Entering anything other than 1, 2, or 3 (including a blank line)
cancels safely with no change.

Create recurring class sessions
Format: recur TASK_ID week WEEK_SPEC
WEEK_SPEC is one or more week numbers or inclusive ranges, separated
by semicolons, for example "1 to 6; 7 to 13" or "3;7;9;11". Week
numbers refer to the external data/academic-calendar.txt file, not a
fixed maximum - ask whoever maintains that file if a week you expect
is missing.

Only a FIXED activity in the ACADEMIC category whose description
contains lecture, lec, tutorial, tut, lab, laboratory, section
teaching, sectional teaching, or sec is eligible (see guide reset
for the same rule used by reset's "keep class schedules" choice).

Example:
  add n/CG3207 Lecture c/ACADEMIC date/2026-08-14 type/FIXED from/16:00 to/18:00 energy/2 sensory/2
  recur 1 week 1 to 6; 7 to 13

Each new session becomes its own independent activity with its own
ID - mark, unmark, edit, and delete only ever affect the one
occurrence you target, not the others. The original activity's own
week is always included automatically; you do not need to list it.

Before creating anything, a preview lists every date to be created
and every date skipped (already the source week, an identical
session that already exists, or a date with no classes in the
calendar file) and asks Continue? (y/n). Only y creates the
sessions; if a target date would overlap another fixed activity,
the whole command is rejected instead of creating a partial batch.
Running the same recur command again creates nothing new.

If data/academic-calendar.txt is missing or cannot be read, recur
reports the problem and every other command keeps working normally.
